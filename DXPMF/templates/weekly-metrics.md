## The two ratios that matter

**Applied / delivered** — is the output actionable?

```
Week:  applied ___ / delivered ___  =  ___%
```

Below ~25% after five deliveries: the findings are true but not worth acting on. Usually a scope problem — the fixes are too abstract or too large.

**Repeat / applied** — does acting once lead to acting again?

```
Week:  repeat ___ / applied ___  =  ___%
```

This is the closest thing to a leading PMF indicator in the kit. A high applied-rate with a zero repeat-rate means you built a one-time cleanup, not a workflow. Workflows compound; cleanups don't.

## Kill-rule check

☐ 10+ qualified conversations, fewer than 3 concrete recent instances → **segment is wrong**
☐ 8+ concierge deliveries, zero fixes applied and zero repeat requests → **wedge is wrong**
☐ Users pull for a surface you refuse to build → **say so out loud and change segment**

Do not kill on: slow scheduling, one bad demo, one loud skeptic, or an unimpressed person outside the segment.
