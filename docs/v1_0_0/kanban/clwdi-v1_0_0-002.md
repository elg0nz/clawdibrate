# MCP server scaffold + packaging (clawdibrate-mcp via uvx)

Stand up the MCP server process and the two-console-script packaging so the whole thing installs and
runs as `uvx clawdibrate-mcp`.

## Context

v1.0.0 ships one package with two entrypoints: `clawdibrate` (downscoped CLI, card 001) and
`clawdibrate-mcp` (server). Built on the official Python MCP SDK (`mcp[cli]`) with FastAPI for the
server app/transport. See SPEC.md decisions #1, #6.

## Acceptance Criteria

- [ ] Add `mcp[cli]` (MCP SDK + CLI extras) and `fastapi` to `pyproject.toml` deps via uv
- [ ] Two console scripts: `clawdibrate` = CLI, `clawdibrate-mcp` = server
- [ ] Server starts over stdio and registers via `.mcp.json`
- [ ] `.mcp.json` example: `{ "command": "uvx", "args": ["clawdibrate-mcp"] }`
- [ ] Package is PyPI-publishable; `uvx clawdibrate-mcp` runs end-to-end
- [ ] Server module reuses existing `clawdibrate/` modules; no logic duplication
- [ ] Empty tool/resource/prompt registries wired (filled by cards 003–008)

## Notes

Depends on the CLI existing (001). Blocks all MCP tool/resource cards. Part of v1.0.0. See SPEC.md.
