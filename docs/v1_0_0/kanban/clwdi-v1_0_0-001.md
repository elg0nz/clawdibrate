# Downscope the CLI to AGENTS.md file manipulation only

Strip the `clawdibrate` CLI down to a single job: deterministic `AGENTS.md` file surgery. No model,
no pipeline, no evidence generation, no skills install. This is the shared primitive both humans and
the MCP `implement` tool use to mutate the file.

## Context

Today `clawdibrate/cli.py` is a broad argparse interface (`--mode`, `--transcript`, `--repo`,
`--synthesize-git-history`, `--scores`, `--dump-session`, `--setup`, full loop). v1.0.0 moves all
orchestration to the MCP server (cards 003–008) and leaves the CLI as file-editing only. See SPEC.md
"Two layers" + decision #7.

## Scope (locked CLI surface)

- [ ] `clawdibrate sections` — list section headings in the active instruction file
- [ ] `clawdibrate get <section>` — print one section's content
- [ ] `clawdibrate replace <section>` — replace a section, **new content read from stdin**
- [ ] `clawdibrate tokens` — per-section + total token counts
- [ ] `clawdibrate init-pointer` — create/repair the AGENTS.md/CLAUDE.md pointer (former `--setup` (a))
- [ ] `clawdibrate scorecard` — read-only Scorecard render from history (see card 008)
- [ ] Backed only by `instruction_files.py` + `tokens.py` (+ scores read for scorecard); no model
- [ ] Remove from the CLI: loop/`--mode`, `--synthesize-git-history`, `--dump-session`, `--scores`,
      `--setup` skills-install + settings.json injection
- [ ] `replace` accepts stdin so the MCP can pass large section bodies without arg-size limits

## Acceptance Criteria

- [ ] All six subcommands work standalone for a human
- [ ] No subcommand makes a model call
- [ ] Old broad flags are gone; `cli.py` reflects the narrow surface
- [ ] `_ensure_permissions()` / settings.json writing removed; `_install_bundled_skills` removed
- [ ] Existing tests updated; new tests cover sections/get/replace/tokens
