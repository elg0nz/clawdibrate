# Scorecard renderer - OVERALL, per-section SCORE+VERDICT, WHY, TOP FIX

Build the renderer that produces the AGENTS.md Scorecard exactly as drawn in the launch post.
This is the headline, user-facing artifact.

## Context

`clawdibrate/scores.py` today prints only a date/avg/token-delta table + sparkline. The
Scorecard needs: OVERALL line, grading-basis line (train/holdout/overfit), per-section bars
with VERDICT strings, the 5 WHY metrics, and the TOP FIX block. Backed by `scores.jsonl`,
`metrics.py`, and the orchestrator's section-suggestion data.

## Acceptance Criteria

- [ ] Renders OVERALL grade + delta + tokens + trend sparkline + run count
- [ ] Renders grading basis (N sessions, train/holdout, overfit flag from `split_transcripts`)
- [ ] Renders per-section SCORE + bar + VERDICT string
- [ ] Renders WHY block: the 5 Tier-1 metrics with labels
- [ ] Renders TOP FIX: highest-impact section, reason, est. token savings, calibrate hint
- [ ] Output matches the mockup in docs/blog/clawdibrate-mcp-launch.md
- [ ] VERDICT/TOP-FIX honor the model-dependency boundary from card 003
