# Drift detection - dead refs for the stale VERDICT

Add a deterministic checker that detects when an AGENTS.md section references files, paths, or
commands that no longer exist, feeding the "stale — N dead refs" VERDICT.

## Context

The Scorecard mockup shows `Known Gotchas … ⚠ stale — 2 dead refs`. That signal does not
exist yet. It is deterministic (no model): resolve referenced paths/commands against the repo.
Directly serves Addy's "keep the context file accurate rather than letting it rot."

## Acceptance Criteria

- [ ] Parses AGENTS.md sections for referenced paths, files, and commands
- [ ] Resolves each against the repo; flags unresolved as dead refs
- [ ] Returns per-section dead-ref counts the renderer can consume
- [ ] Runs with no model call
- [ ] Covered by a unit test with a fixture containing a known dead ref
