# AGENTS.md Scorecard renderer (headline feature)

Build the Scorecard — the launch's killer feature. The human-readable graded report the `score` tool
returns and the `clawdibrate scorecard` CLI command renders read-only.

## Context

`scores.py` today prints only a date/avg/token-delta table + sparkline. The Scorecard adds the graded
per-section view with verdicts and a top fix. Every field must trace to real engine output — no
fabrication. See SPEC.md "Headline feature: the AGENTS.md Scorecard" + decision #8.

## Acceptance Criteria

- [ ] OVERALL grade + delta + tokens(delta) + trend sparkline + run count
- [ ] Grading basis line: N sessions, train/holdout split, overfit flag (`split_transcripts`)
- [ ] Per-section SCORE + bar + VERDICT string (costing tokens / vague / stale N dead refs / earning /
      keep as-is) — verdicts sourced from scores + drift checker (006)
- [ ] WHY block: the 5 Tier-1 metrics (`metrics.py`), labeled
- [ ] TOP FIX: highest-impact section, reason, est. token savings, next step (implement/calibrate)
- [ ] Returned by MCP `score` (structured + rendered) AND by `clawdibrate scorecard` (read-only, no model)
- [ ] Output matches the mockup in docs/blog/clawdibrate-mcp-launch.md
- [ ] No fabricated fields; provenance table in SPEC honored
