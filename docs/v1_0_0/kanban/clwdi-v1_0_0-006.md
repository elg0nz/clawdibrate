# Deterministic drift checker (dead refs for the stale verdict)

Detect when an AGENTS.md section references files/paths/commands that no longer exist, feeding the
Scorecard's "stale — N dead refs" verdict. No model.

## Context

The Scorecard (card 008) shows a "stale — N dead refs" verdict. That signal doesn't exist yet. It is
deterministic — resolve referenced paths/commands against the repo. Serves Addy's "keep the context
file accurate rather than letting it rot." See SPEC.md Scorecard provenance.
