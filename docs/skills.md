# Skills

## User-facing

| Skill | Description |
|-------|-------------|
| `/clawdbrt-loop` | Run transcript-based calibration on recorded sessions, score AGENTS.md failures, and rewrite responsible sections |
| `/clawdbrt-record-start` | Start recording all tool calls, searches, decisions, and user corrections to a JSONL transcript |
| `/clawdbrt-record-stop` | Finalize the active transcript and report a summary of tool calls, searches, actions, and corrections |
| `/clawdbrt-record-session` | Dump the current Claude Code session into a clawdibrate transcript |
| `/clawdbrt-record-from-git` | Bootstrap a transcript from recent git history touching the repo's active instruction file |
| `/clawdbrt-kanban` | Create, move, and manage kanban cards in `docs/vX_Y_Z/kanban/` folders |
| `/clawdbrt-add-new-features` | Propose and build new features as kanban cards (MINOR version) |
| `/clawdbrt-implement` | Read kanban board and implement cards by priority, spawning parallel agents |
| `/clawdbrt-scores` | Show calibration scoreboard for a repo or all tracked repos |
| `/clawdbrt-tokens` | Show per-section token breakdown and budget status for the instruction file |
| `/clawdbrt-presubmit` | Run the Python quality gate (ruff, mypy, bandit, vulture, radon, inline imports) |
| `/clawdbrt-present` | Present the Faros AI take-home deck interactively via chat |
| `/clawdbrt-present-web` | Launch the demo deck as a web slideshow using Slidev (`npx`, no install) |
